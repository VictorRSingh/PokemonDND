# Status and reaction groundwork

Handbook section 7: pure status restrictions, disadvantage sources, paralysis d4, sleep d20, confusion d20 and frozen STR save calculations. These helpers do not mutate encounter state or consume RNG. Callers must supply validated rolls and enforce timing, grace periods, forfeiture and recovery. Opportunity candidate detection checks endpoints only, with caller-supplied reach and disengagement; it does not authorize or execute reactions. Existing switching is unchanged. Do not expose these helpers as a player-authorized command API.
