# Phase 5.2.5
Abilities are extracted from all raw species, including quarantined species. None is an absence marker, not an ability. Descriptions with the same canonical ID are grouped; conflicting wording is retained for later comparison against the handbook, not resolved by guessing. All handlers are unsupported and activation is unclassified. Standard/hidden flags describe occurrence in the dataset, not eligibility for a specific species. Nature modifiers preserve the source dataset (the 20-entry table in the Pokémon 5e handbook, page 11). No stat mutation is performed. Strict validation fails for unresolved description variants. No raw JSON changes. Run `node scripts/validate-normalized-abilities-natures.mjs` from project root; optionally pass the dataset directory or `--strict`.
