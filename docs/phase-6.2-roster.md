# Phase 6.2 — Roster battle prototype

Open the existing battle page as campaign owner or DM. Choose Sandbox to retain the original species-based battle or Campaign roster to select a saved Pokémon and a saved or wild opponent. Only active player members' campaign copies are queried. No database writes occur. Saved HP, AC, level, stats, nickname, selected moves and ability are imported. Legacy storage does not track remaining PP, so PP starts at move maximum. Unsupported moves are disabled; unsupported abilities may require manual resolution. Trainers are displayed as roster owners, not tactical combatants. The existing fixed-distance two-Pokémon limitation remains. Sprites use the existing PokeAPI sprite convention and require network access; alternate forms may show the base sprite. No migration. Run engine tests and verify Next.js compilation and browser behavior locally.
