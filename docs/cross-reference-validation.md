# Cross-reference validation (5.2.6a)

Empty hidden-ability arrays represent absence; nonempty malformed arrays still fail. Ho-oh and Shaymin Land have exact copyright fragments removed from their TM lists, retaining TM100. Original JSON remains unchanged.

Five malformed TM tokens also appear in the supplied Monster Manual itself (Graveler 8087, Cherrim 8687, Alolan Sandslash 566, Toxapex 109, Mimikyu 0). Do not guess replacements. These records remain quarantined pending a decision. Missing moves and conflicting ability descriptions remain unresolved. The validator checks normalized learnsets, abilities and evolution targets; it does not validate egg moves or TM-to-move mappings. Strict mode fails on any normalization issue, missing reference or ability conflict.
