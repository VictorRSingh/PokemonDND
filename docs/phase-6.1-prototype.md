# Phase 6.1: DM battle sandbox
Open an active campaign as owner or human/assisted DM, then Launch battle prototype. Select two species and start. Use supported learned moves and End turn. Reset repeats the seed; reload generates a new seed. Campaign rules are captured server-side. Classic grid rules use fixed positions five feet apart; no movement UI. Manual rolls and weather/terrain are rejected. Species use base stats and base-level supported moves; abilities are not assigned. State is browser-local, not authoritative multiplayer state, and never writes to campaign rosters. No persistence or database migration. Engine tests exercise the same prototype adapter; browser and full application compilation require local dependencies and database.
