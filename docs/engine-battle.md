# Battle integration (Phase 5.6–5.12 foundation)

Pure engine functions, no database or UI changes. `useBattleMove` is the supported atomic attack entry point; it returns a new state and roll details. `advanceBattleTurn` handles basic poison/burn ticks. `campaignBattleRules` maps the existing active Pokémon limit into a validated snapshot. Use canonical registry data, not client-provided species definitions. Arena mode abstracts distance. Grid coordinates are feet and use Chebyshev distance; walking only, opportunity attacks require manual handling. Supported moves: Scratch, Tackle, Vine Whip, Water Gun, Ember, Struggle. All other moves reject explicitly. Registry metadata remains unchanged. Ability effects, weather, terrain, most statuses, switching, reaction triggers, manual adjudication workflow, full event persistence and campaign UI/API wiring are not implemented. Do not expose these low-level functions as an authenticated API without additional validation. The test fixture is synthetic (not a legal progression build). No claim of complete official rules coverage.
