# Incremental combat integration
Attacks now use status disadvantage and restrained-target advantage; incapacitated actors and unresolved paralysis/confusion remain blocked. Poison damage is applied before selecting the next eligible turn, preventing selection of a newly fainted actor. End-turn accepts a current slot member even if fainted; authorization remains the caller's responsibility. Grid replacement uses the outgoing position and rejects occupied positions. Individual switching inherits the outgoing initiative slot (application convention, not a new initiative roll). Full status timing, recovery, grace periods, opportunity execution and official switching geometry remain outstanding. No API or persistence changes.
