# Combat ruleset snapshots (v1)

`createRulesetSnapshot(preset, overrides)` validates and freezes a detached snapshot. `restoreRulesetSnapshot` validates persisted JSON without applying new defaults. Presets: classic (shared initiative, grid, one active Pokémon, PP and reactions enabled); casual (arena, no trainer participation, PP or reactions); expanded (classic plus weather and terrain); custom (classic baseline). Hidden abilities default off. These are proposed application defaults, not new official rules. Overrides must explicitly disable opportunity attacks when disabling reactions, and hidden abilities when disabling abilities. Active Pokémon limit is 1–6. Unknown fields and versions are rejected. All fields are primitives, so shallow freezing suffices. Campaign settings mapping, progression/resource rules, persistence, authorization and enforcement are future work. No campaign settings are changed by this module.
