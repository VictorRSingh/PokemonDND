# Phase 6.3 — Group initiative
Existing sandbox and roster modes remain unchanged unless Group encounter is selected. Select an optional extra ally and opponent. Saved Pokémon are linked to trainer combatants; trainer stats are temporary defaults (level 1, 10 HP, AC 10, all scores 10, speed 30). Campaign rules govern trainer participation, initiative and active Pokémon limits. Shared initiative uses the engine's shared action and bonus action pool. Select an eligible actor and opposing Pokémon target; trainer turns can be ended but trainer attacks are not implemented. Movement and reaction resources are displayed, not spendable from this UI. Grid positions are fixed and range restrictions still apply; arena campaigns are recommended for group testing until movement UI arrives. No persistence changes. Engine tests cover shared slots, target rejection and action spending. Browser and full application compilation require local dependencies.
