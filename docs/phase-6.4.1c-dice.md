# Encounter dice controls
Digital uses the existing seeded engine. Physical prompts for each raw face; hybrid permits a seeded digital face instead. Transactions rerun from the unchanged encounter snapshot until every face is supplied, then commit once. Cancel discards the transaction. Physical overrides still advance the seeded stream; replay requires the entered faces as well as the seed. The encounter rules remain automatic/digital internally; this is a local prototype input adapter, not persisted campaign roll settings. Dice results are shown together after commit with optional CSS animation. Existing unsupported actions remain manual DM rulings. Campaigns configured for engine-native manual mode are still unsupported by the prototype.
